# BECO58.STORE

Catálogo digital streetwear da BECO58.STORE, com layout responsivo, filtro por categorias, carrinho persistente no navegador e checkout via WhatsApp.

## Publicação

O site é estático: basta abrir `index.html` ou ativar o GitHub Pages nas configurações do repositório. As imagens atuais são demonstrativas e podem ser trocadas no array `products` em `script.js`.

## Atualização dos produtos

No arquivo `script.js`, cada produto aceita `name`, `price`, `description`, `category`, `image` e `tag`. Substitua as URLs das imagens e os dados pelos produtos reais da loja.
